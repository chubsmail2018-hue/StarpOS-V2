# ===========================================================================
#  voicebank.txt  -  every line starpOS speaks, in one place
# ===========================================================================
#  Instead of burying spoken text inside each batch file, scripts look the
#  phrase up by ID. Change the wording here and the whole OS changes with it.
#
#  FORMAT:  ID|the words to speak
#
#  Speak one from batch (startup.bat has this as its :say routine):
#
#     set "_ph="
#     for /f "usebackq eol=# tokens=1,* delims=|" %%A in ("voicebank.txt") do (
#         if /I "%%A"=="DESK_WELCOME" set "_ph=%%B"
#     )
#     if defined _ph cscript //nologo "speak.vbs" "%_ph%"
#
#  Spell tricky words the way they should SOUND, not the way they are
#  written. "starp O S" reads better out loud than "starpOS".
# ===========================================================================
